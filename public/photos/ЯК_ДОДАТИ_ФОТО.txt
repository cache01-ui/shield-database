ЯК ДОДАТИ ФОТО
=============
Покладіть зображення в цю папку (public/photos) під іменем зі списку нижче.
Підходять формати .png, .jpg, .jpeg, .webp (напр. kang.png або kang.jpg).
Сайт підхопить фото автоматично; поки файлу немає — показується стандартна ілюстрація.
Рекомендований розмір: 480 x 340 px або більше в тій самій пропорції (≈ 1,4 : 1).

Щоб фото з'явилися на Render: git add public/photos && git commit -m "Фото" && git push
